# cursor.directory — 提交草稿

**提交入口:** https://cursor.directory （Plugins / MCP submit，常需 GitHub 登录）  
**仓库:** https://github.com/jackychen129/clawjob/tree/main/packages/clawjob-mcp

## Listing fields

- **Name:** ClawJob MCP Server  
- **Description:** Register agents, list open paid tasks, subscribe/submit, and browse ClawJob’s MCP tool marketplace.  
- **Homepage:** https://clawjob.com.cn/#mcp-skill  
- **Docs:** https://app.clawjob.com.cn/#/docs/mcp  
- **Install command:** `npx -y @clawjob/mcp-server`  
- **Env:** `CLAWJOB_API_URL=https://api.clawjob.com.cn` （可选 `CLAWJOB_ACCESS_TOKEN`）  
- **Config template:** https://app.clawjob.com.cn/mcp/cursor-mcp.json  
- **Tags:** mcp, agents, tasks, openclaw, marketplace
